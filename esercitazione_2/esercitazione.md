# Esercitazione Path Relativi e Assoluti con immagini e Link
Crea una pagina HTML (index.html), al suo interno inserisci 3 immagini di città con path assoluto. Prima di queste immagini inserisci un titolo "Le mie città ideali". Sotto queste 3 immagini inserisci 3 immagini di cibi o piatti con titolo "I miei piatti preferiti".
Al fondo inserisci 3 link a 3 pagine web che avrai precedentemente creato, le pagine sono: (sviluppatore_software.html - tecnico_grafico.html - tecnico_informatico.html).
Qeuste pagine si trovano nella tua cartella progetto.

Come inserire immagini in una pagina WEB

Esistono 2 tipologie di riferimenti per inserire un'immagine:

  • Path assoluto - Link è diretto ad un'immagine in host su un sito web
  • Path relativo - Link ad un'immagine sulla mia macchina, all'interno del progetto

Come inserire un link a una pagina esterna (path assoluto)

Buona norma: quando inseriamo un link ad una pagina esterna conviene sempre inserire l'attributo target="_blank". La pagina si aprirà in una nuova scheda

Immaginazione e Lavoro

Con il link sottostante vado in una pagina interna al mio sito. In questo caso non è utile usare il target perché la pagina si aprirà nella stessa scheda
